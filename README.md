Week 2: Object-Oriented Programming (OOP)

This repository contains my Week 2 Java Programming Internship assignments and mini project.

Topics Covered

- Classes and Objects
- Constructors
- Inheritance
- Method Overriding
- Polymorphism
- Encapsulation
- Access Modifiers
- Java Collections ("ArrayList")

Assignment 1: Student Class Implementation

File: "Assignments/Student.java"

Created a Student class with roll number, name, and course attributes. The program uses a constructor to initialize the object and a method to display student information.

Assignment 2: Vehicle Inheritance Example

File: "Assignments/VehicleInheritance.java"

Created a parent class named "Vehicle" and two child classes named "Car" and "Bike".

The program demonstrates inheritance, method overriding, and runtime polymorphism.

Mini Project: Library Management System

Folder: "LibraryManagementSystem/"

Classes

- "Book.java" — Stores book details and availability.
- "User.java" — Stores user information.
- "Library.java" — Manages books, borrowing, and returning.
- "LibraryManagementSystem.java" — Main class to run the project.

Features

- Add books
- Display available and borrowed books
- Borrow books
- Return books
- Check book availability

How to Run

Assignment 1

cd Assignments
javac Student.java
java Student

Assignment 2

javac VehicleInheritance.java
java VehicleInheritance

Mini Project

cd LibraryManagementSystem
javac *.java
java LibraryManagementSystem

Learning Outcome

Through these assignments, I practised Java OOP concepts and learned how to organize a simple multi-class Java project.
